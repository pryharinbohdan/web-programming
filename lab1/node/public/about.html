Моя реалізація

Сервер на Node.js використовує вбудовані модулі http, fs та path. Запит парситься за допомогою URL об'єкта для отримання чистого шляху (без урахування query-параметрів). Зіставлення маршрутів визначає, який файл із папки public (index.html, about.html або 404.html) слід прочитати через fs.readFile та повернути із відповідним статус-кодом (200 або 404) та заголовком Content-Type (text/html; charset=utf-8 або text/css; charset=utf-8).
